# `.pre-commit-config.yaml`

## Purpose

Chạy hai hook trước commit:

1. Local `notebook-privacy`: `python scripts/check_notebook_privacy.py --staged`,
   `always_run`, tự đọc staged notebooks và chặn output/identifier/credential.
2. Ruff từ `astral-sh/ruff-pre-commit` revision `v0.15.22`, lint với
   `--exit-non-zero-on-fix`.

## Why it matters

Notebook output có thể nhúng MIMIC identifier/report text dù diff khó nhìn. Hook
privacy là chốt tuân thủ DUA, không được bypass. `language: system` nghĩa là
Python hiện tại phải chạy được script local.

## Setup

```bash
pip install pre-commit
pre-commit install
```
